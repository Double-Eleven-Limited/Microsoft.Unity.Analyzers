# PSA001 Profiler sample is left open

A method, accessor, or anonymous function exits with an open profiler sample.

## Examples of patterns that are flagged by this analyzer

```csharp
void UpdateState()
{
    UnityEngine.Profiling.Profiler.BeginSample("UpdateState");
    UpdateCurrentState();
}
```

## Solution

Close the sample on every path. A `try`/`finally` block or
`ProfilerMarker.Auto()` is preferred when the body can throw or exit early.

```csharp
void UpdateState()
{
    UnityEngine.Profiling.Profiler.BeginSample("UpdateState");
    try
    {
        UpdateCurrentState();
    }
    finally
    {
        UnityEngine.Profiling.Profiler.EndSample();
    }
}
```

The analyzer also recognizes `BeginProfilerSample` wrappers used by
`TimeWarning`. Analysis is performed within each method, so an intentional
sample lifetime transferred to `Dispose` should suppress PSA001 narrowly at the
wrapper call and document that ownership transfer.
