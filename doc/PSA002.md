# PSA002 Profiler EndSample has no matching BeginSample

An `EndSample` call has no matching open profiler sample in the current method.

## Examples of patterns that are flagged by this analyzer

```csharp
void UpdateState()
{
    UpdateCurrentState();
    UnityEngine.Profiling.Profiler.EndSample();
}
```

## Solution

Remove the unmatched call or add the corresponding `BeginSample` in the same
method and ensure that both calls are balanced on every control-flow path.

```csharp
void UpdateState()
{
    UnityEngine.Profiling.Profiler.BeginSample("UpdateState");
    UpdateCurrentState();
    UnityEngine.Profiling.Profiler.EndSample();
}
```

The analyzer also recognizes `EndProfilerSample` wrappers used by `TimeWarning`.
Analysis is performed within each method, so an intentional sample opened by a
separate lifetime method should suppress PSA002 narrowly at the wrapper call and
document where the sample is opened.
