# PSA003 Profiler sample can be left open by early exit

An early `return`, `throw`, `break`, `continue`, or `yield break` can bypass the
matching `EndSample` call.

## Examples of patterns that are flagged by this analyzer

```csharp
void UpdateState(bool enabled)
{
    UnityEngine.Profiling.Profiler.BeginSample("UpdateState");

    if (!enabled)
        return;

    UpdateCurrentState();
    UnityEngine.Profiling.Profiler.EndSample();
}
```

## Solution

Use `try`/`finally` or `ProfilerMarker.Auto()` so the sample is closed for every
control-flow path.

```csharp
void UpdateState(bool enabled)
{
    UnityEngine.Profiling.Profiler.BeginSample("UpdateState");
    try
    {
        if (!enabled)
            return;

        UpdateCurrentState();
    }
    finally
    {
        UnityEngine.Profiling.Profiler.EndSample();
    }
}
```
